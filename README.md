# Проект (homework): Работа с банковскими данными

Набор утилит для обработки банковской информации: маскировка номеров карт и счетов, форматирование дат, фильтрация и сортировка транзакций, загрузка данных из JSON и конвертация валют через внешний API.

## Основные функции

### Маскировка данных
- **`mask_account_card(user_input: str) -> str`**  
  Принимает строку с названием карты/счёта и номером, возвращает замаскированную версию.  
  Пример:  
  `"Maestro 1596837868705199"` → `"Maestro 1596 83** **** 5199"`  
  `"Счет 73654108430135874305"` → `"Счет **4305"`

- **`get_mask_card_number(number: str) -> str`**  
  Маскирует номер карты: первые 6 и последние 4 цифры видны, остальное — звёздочки.

- **`get_mask_account(number: str) -> str`**  
  Маскирует номер счёта: отображаются только последние 4 цифры.

### Форматирование даты
- **`get_date(date_str: str) -> str`**  
  Преобразует дату из формата `"2018-07-11T02:26:18.671407"` в `"11.07.2018"`.

### Работа с транзакциями
- **`filter_by_state(list_of_dict: list, state: str = "EXECUTED") -> list`**  
  Возвращает список транзакций с указанным статусом (`EXECUTED`, `CANCELED` и т.д.).

- **`sort_by_date(list_of_dict: list, reverse: bool = True) -> list`**  
  Сортирует транзакции по дате. По умолчанию — от новых к старым.

### Генераторы и фильтры
- **`filter_by_currency(transactions: list, currency_code: str)`**  
  Генератор, возвращающий транзакции в указанной валюте (например, `"USD"`).

- **`transaction_descriptions(transactions: list)`**  
  Генератор, возвращающий описания транзакций.

- **`card_number_generator(start: int, end: int)`**  
  Генератор, создающий валидные номера банковских карт в заданном диапазоне (от `0000 0000 0000 0001` до `9999 9999 9999 9999`).

### Логирование функций
- **`@log(filename=None)`** — декоратор для автоматического логирования вызовов функций.  
  - При `filename=None` — логи выводятся в консоль.
  - При указании имени файла (например, `filename="my_log.log"`) — записываются в файл в режиме добавления.

  Пример использования:
  ```python
  from src.decorators import log

  @log(filename="my_log.txt")
  def my_function(x: int, y: int) -> int:
      return x + y

  my_function(1, 6)
### Загрузка транзакций из JSON
- **`data_for_transactions(file_path: str) -> list`**  
  Читает JSON-файл и возвращает список транзакций.  
  - Если файл не найден, пустой или содержит не список — возвращает пустой список `[]`.  
  - Файл должен находиться в: `data/operations.json`.

### Конвертация валют
- **`external_api.currency_conversion(transaction: dict) -> float`**  
  Возвращает сумму транзакции в рублях (`float`).  
  - Поддерживает валюты: `RUB`, `USD`, `EUR`.  
  - Для конвертации используется [Exchange Rates Data API](https://apilayer.com/).  
  - API-ключ берётся из переменной окружения `API_KEY`.

>  **Важно**: файл `.env` с вашим ключом **должен быть в `.gitignore`**.  
> В репозиторий коммитится только шаблон: `.env.example`.

### Логирование

В проекте используется модуль `logging` из стандартной библиотеки Python. Каждый функциональный модуль имеет собственный логгер, записывающий сообщения в отдельный файл.

- **Имена файлов логов**: `{название_модуля}.log`  
  Примеры: `utils.log`, `masks.log`

- **Режим записи**: файл перезаписывается при каждом запуске (`mode='w'`)

- **Формат сообщений**:
>`2025-11-16 17:38:16,070 - masks - INFO - Принимается номер карты
2025-11-16 17:38:16,070 - masks - WARNING - Не введен номер карты
2025-11-16 17:38:16,071 - masks - ERROR - Счёт '1111' имеет неверный формат.`

## Тестирование

Проект покрыт автоматизированными тестами с использованием фреймворка `pytest`.

### Как запустить тесты и посмотреть оценку покрытия  

Убедитесь, что установлен `pytest`:

```bash
pip install pytest
```
Команда для просмотра оценки покрытия тестами:
```bash 
pytest --cov
```
Генерация отчета о покрытии в HTML-формате: 
```bash
pytest --cov=src --cov-report=html
```
